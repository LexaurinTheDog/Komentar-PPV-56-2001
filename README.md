# Komentář k zákonu č. 56/2001 Sb., o podmínkách provozu vozidel na pozemních komunikacích

Odborný komentář k **zákonu č. 56/2001 Sb., o podmínkách provozu vozidel na pozemních komunikacích (PPV)** — předpisu technické způsobilosti vozidel: registr silničních vozidel a zápisy vlastníků a provozovatelů, vyřazení a zánik vozidla, schvalování typu i jednotlivá schválení, technické prohlídky a stanice technické kontroly. Doplňuje sesterské komentáře ZSP-361-2000 a ZPK-13-1997.

Konsolidované znění: dokument e-Sbírky `SB-2001-00056_2026-01-01`.
